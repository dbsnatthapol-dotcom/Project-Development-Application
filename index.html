❓ วิธีใช้งาน PRIME — Project Management Platform

🗂 Navigation (แถบซ้าย)

คลิก icon หรือปุ่มในแถบซ้ายเพื่อสลับ Module · กดปุ่ม « ด้านล่างเพื่อย่อ/ขยาย Sidebar

📁 Multi-Project

คลิกกล่อง โปรเจกต์ปัจจุบัน ด้านบน Sidebar เพื่อเปิด Project Manager · สร้าง/โหลด/ลบโปรเจกต์ได้

💾 บันทึก / Export

บันทึกอัตโนมัติ (localStorage) · ปุ่ม ส่งออก = ดาวน์โหลด .json · ปุ่ม นำเข้า = อัปโหลดไฟล์ที่เคย Export

📄 รายงาน / พิมพ์

กด 📄 รายงาน → เลือก Module → เลือกขนาดกระดาษ → กด 🖨 พิมพ์ หรือ 📊 Excel

🖼 รูปภาพ

อัปโหลดรูปได้ใน Daily Log / Issues / Sign-off / Training · คลิกรูปเพื่อขยาย Lightbox

💡 เคล็ดลับ

  • เปิดด้วย Chrome หรือ Edge เพื่อการพิมพ์ที่ดีที่สุด
  • ใช้งานออฟไลน์ได้ และรองรับแท็บเล็ต/มือถือ
  • กดย่อ Sidebar เพื่อให้มีพื้นที่แสดงผลมากขึ้นบนจอเล็ก
⚠ ข้อมูลเก็บใน Browser ของเครื่องนี้ · Export .json สำรองก่อนเปลี่ยนเครื่อง
